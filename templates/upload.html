How to export bookmarks from X (desktop, one time)

  1. On desktop Chrome/Edge, install Tampermonkey or Violentmonkey.
  2. Add assets/collector.user.js from this repo as a new userscript.
  3. Open https://x.com/i/bookmarks, scroll to the bottom until everything loads.
  4. Click the Download button the script adds — it saves bookmarks_raw.jsonl.
  5. Send that file to your phone (email / cloud drive / chat with yourself).
  6. Open this site on your phone, log in, upload the file here.
  7. Then: Discover Categories → Classify All → work through Needs Review → search & export.
This app never asks for your X login, password, or cookies. The first version does not log in to X directly.
